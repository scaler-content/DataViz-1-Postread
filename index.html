Why Visualize? — Exploratory vs Explanatory

❝ You already know how to make a chart. The real skill is knowing which of two jobs it is doing — and building it for that job.

Every chart does one of two jobs. Knowing which job you're on changes every decision:

Exploratory for youExplanatory for the board
AudienceYouSomeone else — board, client, manager
GoalFind somethingCommunicate ONE finding
How manyMany, fastOne, polished
DefaultsFine as-isNever good enough
Time on itSecondsDeliberate

Exploratory — quick, rough

# Fast — just see the data
sns.countplot(data=vg, x='Genre')
plt.show()
👤

Works for you. Labels overlap, no title, default palette — that's fine. You're exploring.

Explanatory — board-ready

# Sorted, horizontal, one bar
# highlighted, finding in title
# → builds in Section 3
🏢

Sorted, one colour for the finding, title = the sentence the chart makes.

⚠️
Explanatory ≠ "prettier"

It means one finding, made obvious. If a chart has no single point to make, keep it rough. Save your effort for the one that goes in the deck.

02
Matplotlib Architecture — Figure, Axes, Axis

❝ Seaborn draws the chart. Matplotlib owns the canvas it is drawn on. Master the canvas and you can change anything.

ObjectWhat it isAnalogy
FigureThe whole canvas / windowThe sheet of paper
AxesOne plot on that canvas (its own title, x and y)One chart drawn on the sheet
AxisA single x or y ruler on an AxesThe number lines on that chart

One Figure can hold many Axes — that's how dashboards work. Each Axes has two Axis objects: x and y.

Two Styles — plt. vs Object API

State machine (plt.) — works for one chart, breaks with more:

sns.countplot(data=vg, x='Genre')
plt.title('Games by Genre')   # guesses
plt.show()

Object API — professional default, explicit:

fig, ax = plt.subplots(figsize=(7,4))
sns.histplot(data=vg, x='Global_Sales',
            bins=30, ax=ax)      # draw ONTO ax
ax.set_title('Sales distribution')
ax.set_xlim(0, 5)
plt.show()
🚨
Never mix the two styles

Once you write fig, ax = plt.subplots(), finish with ax. methods. Using plt.title() afterward sets it on the current Axes — which may not be the one you think.

Key ax. Methods

MethodWhat it sets
ax.set_title(...)Title of this plot
ax.set_xlabel / set_ylabelAxis labels
ax.set_xlim / set_ylimAxis range (zoom)
ax.set_xticks / set_xticklabelsTick positions and text
ax.legend(...)Legend for this plot
ax.spines['top'].set_visible(False)Hide a border line

03
Styling & Titles — Turning Data into a Sentence

❝ Styling removes what distracts. A title that states the finding adds the one thing that matters.

Step-by-step: Plain → Board-ready

Step 1 — the plain chart (exploratory):

avg_genre = vg.groupby('Genre')['Global_Sales'].mean().sort_values(ascending=False)

fig, ax = plt.subplots(figsize=(8, 4.5))
ax.barh(avg_genre.index[::-1], avg_genre.values[::-1])
plt.show()
# Correct — but makes no point. What's the finding?

Step 2 — colour with intent + declutter:

fig, ax = plt.subplots(figsize=(8, 4.5))
bars = ax.barh(avg_genre.index[::-1], avg_genre.values[::-1],
               color='#9aa7b8')             # ① all grey

bars[-1].set_color('#2E86AB')              # ② highlight ONE bar

ax.set_title('Platform games earn the most per title', loc='left')  # ③ finding in title
ax.set_xlabel('Avg global sales (M units)')
ax.set_ylabel('')
ax.spines['top'].set_visible(False)       # ④ remove chartjunk
ax.spines['right'].set_visible(False)
plt.show()

Legend, Grid & Ticks

# Action vs Sports releases by year
yrg = (vg[vg['Genre'].isin(['Action', 'Sports'])]
       .groupby(['Year', 'Genre']).size().reset_index(name='Releases'))

fig, ax = plt.subplots(figsize=(8, 4.5))
for g, c in [('Action', '#22c55e'), ('Sports', '#f87171')]:
    d = yrg[yrg['Genre'] == g]
    ax.plot(d['Year'], d['Releases'], label=g, color=c)

ax.set_xticks(range(1996, 2017, 4))          # custom ticks
ax.grid(True, axis='y', alpha=0.3)           # faint gridlines
ax.legend(loc='upper right', ncol=2, frameon=False, title='Genre')
plt.show()

04
Subplots & the Mini Dashboard

❝ One Figure, many Axes. That is all a dashboard is — several charts on one canvas, telling one connected story.

plt.subplots(nrows, ncols) returns the Figure and a grid of Axes you index like a table:

# 1 row, 2 columns
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

sns.barplot(data=vg, y='Genre', x='Global_Sales', errorbar=None, ax=axes[0])
axes[0].set_title('Average sales per game')

sns.lineplot(data=yr, x='Year', y='Name', ax=axes[1])
axes[1].set_title('Releases per year')

fig.tight_layout()   # stop titles / labels overlapping
plt.show()
🗺️
Indexing the grid

1×2: axes[0], axes[1]
2×2: axes[0,0] top-left · axes[0,1] top-right · axes[1,0] bottom-left · axes[1,1] bottom-right

Build the Mini Dashboard

gc  = vg['Genre'].value_counts()
yr  = vg.groupby('Year')['Name'].count().reset_index()
top = vg['Platform'].value_counts().head(6).index
tot = (vg[vg['Platform'].isin(top)]
       .groupby('Platform')['Global_Sales'].sum()
       .sort_values(ascending=False))

fig, axes = plt.subplots(2, 2, figsize=(13, 8))

sns.barplot(x=gc.values, y=gc.index, ax=axes[0, 0])
axes[0, 0].set_title('Catalogue is largest in Action', loc='left')

sns.histplot(data=vg, x='Global_Sales', bins=30, ax=axes[0, 1])
axes[0, 1].set_title('Most titles sell little; a few are hits', loc='left')

sns.lineplot(data=yr, x='Year', y='Name', ax=axes[1, 0])
axes[1, 0].set_title('Releases peaked, then fell', loc='left')

sns.barplot(x=tot.index, y=tot.values, ax=axes[1, 1])
axes[1, 1].set_title('Total sales for top-6 platforms', loc='left')

fig.suptitle('Video Game Sales — Catalogue Health at a Glance', fontsize=15)
fig.tight_layout()
plt.show()
⚠️
Two dashboard failure modes

Overcrowding — more than ~4 panels and nobody reads any.
Clipping — labels cut off: always finish with fig.tight_layout().
A dashboard needs one headline; panels without a shared story are just four charts.

Chart Selection Framework

❝ Pick the chart from the question, never the question from the chart.

Two questions decide the chart:

1. By data shape

If you have…Use
One categorical variableCountplot / bar chart
One continuous variableHistogram, KDE, box plot
Two continuous variablesScatter, line (if one is time)
One categorical + one continuousGrouped bar, grouped box
Two categorical variablesStacked / dodged bar (Section 6)
Multivariate (3+)→ DV-2 next lecture

06
Stacked & Dodged Bars

❝ A single bar gives one number per group. Split each bar by a second category and the board sees what it is made of.

Stacked Bar — part-to-whole across groups

top_plat = vg['Platform'].value_counts().head(6).index
top_gen  = ['Action', 'Sports', 'Shooter', 'Role-Playing']
ct = pd.crosstab(vg['Platform'], vg['Genre']).loc[top_plat, top_gen]

ax = ct.plot(kind='bar', stacked=True, figsize=(8, 4.5))
ax.set_title('Number of games by platform and genre', loc='left')
ax.set_ylabel('Number of games'); ax.set_xlabel('')
ax.tick_params(axis='x', rotation=0)
plt.show()

Dodged (Grouped) Bar — compare segment sizes

sub = vg[vg['Platform'].isin(top_plat) & vg['Genre'].isin(top_gen)]

fig, ax = plt.subplots(figsize=(9, 4.5))
sns.countplot(data=sub, x='Platform', hue='Genre', ax=ax,
              order=list(top_plat), hue_order=top_gen)
ax.set_title('Genre counts per platform (dodged)')
plt.show()
💡
Stacked vs Dodged — decision rule

Stacked: question is about the total and what it's made of.
Dodged: question is about comparing one segment across categories.
